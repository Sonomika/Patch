OLYMPUS memory leaks
====================

Photos in this folder flash up on the screens for a split second when they glitch.
Each photo is shown at most once per play-through, in a random order.

Included (all public domain or CC0):
  cat.jpg       Chelsea the cat, by Stefan van der Walt (CC0, via scikit-image)
  coffee.jpg    coffee cup, by Rachel Michetti (CC0, via scikit-image)
  clock.jpg     motion-blurred wall clock, by Stefan van der Walt (public domain, via scikit-image)
  camera.jpg    photographer with a camera, by Lav Varshney (CC0, via scikit-image)
  rocket.jpg    Falcon 9 launch, SpaceX (public domain, via scikit-image)
  brick.jpg     brick wall (CC0Textures, via scikit-image)
  grass.jpg     grass (CC0, via scikit-image)
  raccoon.jpg   raccoon face (public-domain-image.com, via SciPy)
  stairs.jpg    people climbing stairs (public-domain-image.com, via SciPy)

Add your own by saving a .jpg here under any of these names:
  dog.jpg  bird.jpg  fish.jpg  horse.jpg  owl.jpg  spaghetti.jpg  person.jpg
Names that are missing are simply skipped.

Landscape photos work best; they are cropped to fill each screen.
To add more names, edit olLeakPhotos in patches/security/patch.js.
